# GIBDD-Supabase

Перенос **исходной системы «Ведомость ДПС / GIBDD-DPS v2»** на Supabase без замены её рабочего интерфейса и модели данных.

## Система

- Журнал остановок ТС.
- 6 исходных показателей: остановки, действия, штрафы, предупреждения, задержания, лишения.
- Поиск по ФИО, паспорту, ВУ, госномеру и данным действий.
- Фильтры по причине, действию и игровой дате.
- Остановка ТС с теми же полями исходной версии.
- «Пробить по паспорту».
- Карточка остановки.
- Несколько действий внутри одной остановки.
- Штраф / письменное предупреждение / арест-задержание / лишение права управления.
- Статья, постановление, номер постановления, примечание.
- Создание, редактирование и удаление остановок и действий.
- Сортировка, пагинация, экспорт, импорт, печать и горячие клавиши.

## Supabase

- `inspectors` — профиль инспектора, связанный с `auth.users`.
- `gibdd_stops` — остановки ТС.
- `gibdd_actions` — действия, принадлежащие остановкам.
- RLS ограничивает данные текущим активным инспектором.

## Файлы

- `index.html` — исходный интерфейс GIBDD-DPS v2 с закрытым окном авторизации.
- `css/style.css` — исходный стиль интерфейса без Google Fonts/woff2-зависимости.
- `js/app.js` — исходная логика журнала, адаптированная с localStorage на Supabase.
- `js/auth.js` — вход по email/паролю и привязка к профилю инспектора.
- `js/config.js` — подключение Supabase.
- `supabase/schema.sql` — таблицы и RLS.

## Настройка

1. Выполнить `supabase/schema.sql` в Supabase SQL Editor.
2. Создать пользователя в Authentication → Users.
3. Связать его UUID с записью `public.inspectors`.
4. Открыть приложение и войти по email/паролю.

`service_role`/Secret key в браузерный код добавлять нельзя.
